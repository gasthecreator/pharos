Kill / Restart a Cassandra Node

Partition dc-us / dc-eu

Real tc netem 100% packet loss between every dc-us and dc-eu Cassandra container (the same mechanism internal/faultinjection's own tests use). Auto-heals after 60s if not healed manually first.

Partition a Site's Edge

Requires that site's pharos-edge to be running with its own --enable-chaos flag. Its store-and-forward queue (§2.1) keeps buffering locally while partitioned.

Inject a Duplicate Delivery

Submits the identical event twice in a row through the real pipeline — the correct outcome is both calls returning HTTP 200 with exactly one Kafka publish, not a rejection or a double-write.

Skew a Site's Clock

Submits one real event whose clinical event time is offset from now by the given amount — a negative skew (e.g. -2h30m) simulates a site whose clock runs behind, exercising the real late-arrival/watermark path live.
