# Project history

Process records, kept unedited because their value is that they are dated and
were not cleaned up after the fact:

- [`WORKLOG.md`](WORKLOG.md): a dated log of every implementation session, by
  whoever did it (newest first).
- [`ARCHITECTURE_PROPOSALS.md`](ARCHITECTURE_PROPOSALS.md): the proposal and
  review trail for non-trivial design changes, including the review findings
  that sent several designs back.

For the readable *why* behind each decision, see [`../adr/`](../adr/); for
current status and scope, see [`../../PLAN.md`](../../PLAN.md).
